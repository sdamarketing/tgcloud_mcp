## Из npm {#npm}

```bash
npm install -g tgcloud-mcp
tgcloud-mcp setup     # мастер настройки клиента
```

Мастер записывает MCP-конфиг и спрашивает, ставить ли
[Agent Plugin](https://agent-plugins.org) (каталог `agent-plugin/` в репозитории).
Копия попадает в `~/.tgcloud-mcp/agent-plugin`. Для Cursor — в
`~/.cursor/plugins/local/tgcloud`. Для VS Code — запись в `chat.pluginLocations`.
Codex, Copilot и Kiro подхватывают тот же каталог через свой UI плагинов.

Claude Code и opencode продолжают использовать MCP-конфиг. Скилл:

```bash
npx skills add sdamarketing/tgcloud_mcp
```

## Одна команда {#curl-bash}

```bash
curl -fsSL https://raw.githubusercontent.com/sdamarketing/tgcloud_mcp/main/install.sh | bash
```

Клонирует в `~/.tgcloud-mcp`, собирает, запускает мастер. Повторный запуск обновляет.
Скрипт рисует баннер в рамке (синий градиент в truecolor-терминале) и спиннер
на время клонирования, установки и сборки. Мастер читает `/dev/tty`, поэтому
вопросы задаются и при `curl | bash`.

## Docker {#docker}

```bash
docker run -i --rm ghcr.io/sdamarketing/tgcloud-mcp
```

## Конфиги клиентов {#clients}

**opencode** (`~/.config/opencode/opencode.json`):

```json
{ "mcp": { "tgcloud": { "type": "local", "command": ["npx", "-y", "tgcloud-mcp"], "enabled": true } } }
```

**Claude Code / Cursor:**

```json
{ "mcpServers": { "tgcloud": { "command": "npx", "args": ["-y", "tgcloud-mcp"] } } }
```

**VS Code** (`mcp.json`):

```json
{ "servers": { "tgcloud": { "type": "stdio", "command": "npx", "args": ["-y", "tgcloud-mcp"] } } }
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `TGCLOUD_CLI` | `npx` | Команда запуска CLI (можно обёртку с прокси) |
| `TGCLOUD_CLI_ARGS` | `tgcloud` | Аргументы перед субкомандой |
| `TGCLOUD_TIMEOUT_MS` | `120000` | Таймаут одной команды. `deploy` даёт сборке не меньше 300000 мс |
| `TGCLOUD_TOKEN` | — | CLI access token вместо `tgcloud login` |
