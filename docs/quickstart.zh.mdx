# 快速开始

## 1. 令牌

@BotFather → 你的机器人 → **Serverless → CLI Access → Access token**。
格式是 `app<id>:<secret>`，不是 Bot API 令牌（`123456:AA…`）。
先为这个机器人打开 Serverless。

## 2. 对助手说

```
你：   在 ~/bots/echo 创建一个机器人
助手： create_project → 索要 CLI access token → login_bot
      → 编辑 tgcloud/handlers/message.js → push → webhook_sync
```

机器人已经在线。不必真的发消息也能测逻辑：

```
助手： run_handler { module: 'handlers/message', args: '{ chat: { id: 1 }, text: "hi" }' }
```

`run_handler` 也能运行 endpoint。init data 放在 `ctx` 里。
