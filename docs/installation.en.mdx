# Installation

Requires **Node.js 20+**. The platform CLI itself requires Node.js 18+.

## From npm

```bash
npm install -g tgcloud-mcp
tgcloud-mcp setup     # client setup wizard
```

The wizard writes the MCP config. It also asks whether to install the
[Agent Plugin](https://agent-plugins.org) (`agent-plugin/` in this repo):
a copy lands in `~/.tgcloud-mcp/agent-plugin`. Cursor gets
`~/.cursor/plugins/local/tgcloud`. VS Code gets a `chat.pluginLocations` entry.
Codex, Copilot, and Kiro load that same directory through their plugin UI.

Claude Code and opencode keep using the MCP config. Add the skill with:

```bash
npx skills add sdamarketing/tgcloud_mcp
```

## One-liner (macOS / Linux / WSL)

```bash
curl -fsSL https://raw.githubusercontent.com/sdamarketing/tgcloud_mcp/main/install.sh | bash
```

Clones to `~/.tgcloud-mcp`, builds, runs the wizard. Re-running updates.

## Docker

```bash
docker run -i --rm ghcr.io/sdamarketing/tgcloud-mcp
```

## Manual client configs

**opencode** (`~/.config/opencode/opencode.json`):

```json
{ "mcp": { "tgcloud": { "type": "local", "command": ["npx", "-y", "tgcloud-mcp"], "enabled": true } } }
```

**Claude Code / Cursor:**

```json
{ "mcpServers": { "tgcloud": { "command": "npx", "args": ["-y", "tgcloud-mcp"] } } }
```

**VS Code** (`mcp.json`):

```json
{ "servers": { "tgcloud": { "type": "stdio", "command": "npx", "args": ["-y", "tgcloud-mcp"] } } }
```

## Environment variables

| Variable | Default | Purpose |
|---|---|---|
| `TGCLOUD_CLI` | `npx` | CLI launcher command (can be a proxy wrapper) |
| `TGCLOUD_CLI_ARGS` | `tgcloud` | Prefix args before the subcommand |
| `TGCLOUD_TIMEOUT_MS` | `120000` | Per-command timeout. `deploy` allows at least 300000 ms for `npm run build` |
| `TGCLOUD_TOKEN` | — | CLI access token instead of `tgcloud login` |
