# Ресурсы

Сервер отдаёт справку платформы как MCP-ресурсы. Агент читает их без вызова
инструмента. Текст английский — тот же язык, что у core.telegram.org/bots/serverless,
чтобы справочник можно было сверять со страницей платформы.

| URI | Содержание |
|---|---|
| `tgcloud://docs/project-structure` | Каталог `tgcloud/`, handlers, endpoints, lib, schema.js. Импорты проекта — относительный путь **с** `.js`. Хостинг статики Mini App |
| `tgcloud://docs/cli` | Справочник CLI: команды, `--dry-run` / `--safe` / `--yes` / `--local`, upgrade, webhook |
| `tgcloud://docs/sdk-db` | `sdk/db`: типы колонок (`text`, `integer`, `real`, `numeric`, `blob`, `boolean`, `json`) и mode, query builder, raw SQL, без foreign keys, дропы через `.deprecated` |
| `tgcloud://docs/sdk-api` | `sdk/api`: весь Bot API, `BotApiError`, `InputFile` |
| `tgcloud://docs/sdk-fetch` | `sdk/fetch`: HTTP-клиент, body-хелперы, лимит 32 МБ |
| `tgcloud://docs/limits` | Задокументированные лимиты и квоты, которые не опубликованы |

Внутри скаффолда сначала читайте `AGENTS.md` и `docs/tgcloud-sdk.md`.
Они совпадают с CLI, который создал проект. Ресурсы — запасной справочник,
когда проекта под рукой нет.

Держатель истины в репозитории: `resources/docs/*.md`. `npm run docs:check`
проверяет, что каждый файл зарегистрирован, что две копии скилла совпадают
и что у каждой английской страницы есть соседи ru, zh, ar, de и fr.

## Лимиты платформы

`tgcloud://docs/limits` собирает опубликованные лимиты: 50 МБ на загрузку в
Bot API (10 МБ для фото), 20 МБ на скачивание через `getFile` и 32 МБ на тело
ответа `fetch`.

Квоты времени выполнения — память, CPU, таймаут handler и endpoint, частота
вызовов, размер базы — **не опубликованы**. Не выдумывайте числа. `run_handler`
печатает время выполнения запуска: измеряйте свой путь и держите handler
коротким.
