# tgcloud-mcp

[English](index.en) · [中文](index.zh) · [العربية](index.ar) · [Deutsch](index.de) · [Français](index.fr)

MCP-сервер, который учит AI-ассистента управлять **serverless-ботами Telegram**
(платформа `@tgcloud`, core.telegram.org/bots/serverless): скаффолд проекта,
привязка бота, handlers и endpoints, деплой, миграции БД, вебхуки.

Работает с любым MCP-клиентом: opencode, Claude Code, Cursor, Claude Desktop,
VS Code (Copilot), Windsurf, Zed. Тот же сервер и скилл поставляются одним
[Agent Plugin](https://agent-plugins.org) для Codex, Cursor, Copilot, Kiro и VS Code.

## Возможности

- **16 инструментов** — команды `tgcloud` CLI, включая `upgrade` (layout до 0.2.0) и `deploy` (сборка, затем push)
- **Ресурсы** `tgcloud://docs/*` — встроенная справка платформы на английском, вровень с официальной документацией
- **Guardrails** — деструктивные операции требуют `confirm: true`, токены маскируются
- **Мультипроектность** — каждый инструмент принимает абсолютный `project_dir`

## Быстрый старт

```bash
npm install -g tgcloud-mcp && tgcloud-mcp setup
```
