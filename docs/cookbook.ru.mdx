# Кукбук

Длинный рецепт с выводом CLI, снятым с реального бота «Дневник обучения»:

[docs/cookbook-srl-bot.md](https://github.com/sdamarketing/tgcloud_mcp/blob/main/docs/cookbook-srl-bot.md)

Что внутри:

1. Скаффолд и логин (два вида токена)
2. Handler сообщений и таблица БД
3. Деплой и миграции (`--dry-run`, `--safe`, `--yes`)
4. Inline-кнопки (`callback_query`)
5. Mini App: `endpoints/`, статика, `tgcloud.jsonc`, затем `deploy`, чтобы сборка была свежей
6. Диагностика молчащего бота (`webhook_status`, затем `webhook_sync`)

Грабли, которые разобраны там и в `tgcloud://docs/*`: относительные импорты с `.js`,
нет foreign keys, дропы только через `.deprecated`, push не собирает фронтенд
и не мигрирует базу, новый handler может оставить вебхук рассинхронизированным.
